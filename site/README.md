# Lock In Tracker

A GitHub Pages-ready daily tracker for Vishwajeet and Abdul.

## Publish it

1. Create an empty GitHub repository.
2. Upload the full project, keeping the `site` folder and `.github/workflows/deploy-pages.yml` file.
3. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the source.

GitHub Pages only hosts static files. This first version stores data in the browser where it is used. For both people to see the same live entries, connect a shared database and authentication service before publishing.
